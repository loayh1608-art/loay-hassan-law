موقع مؤسسة لؤي حسان للمحاماة والاستشارات القانونية

الملفات:
- index.html: الصفحة الرئيسية ومحتوى الموقع
- style.css: التصميم والألوان والاستجابة للموبايل
- script.js: القائمة والمساعد الإرشادي

التصميم: أسود وأبيض وذهبي. يحتوي الموقع على دليل استرشادي لمجالات القضايا والعقود، ورابط Google Maps المرسل من صاحب الموقع، وبيانات التواصل.

النشر على GitHub Pages:
1. افتح مستودع louay-hassan-law.
2. من Add file اختر Upload files.
3. ارفع الملفات الثلاثة مباشرة في جذر المستودع، وليس داخل مجلد فرعي.
4. اضغط Commit changes ووافق على استبدال الملفات القديمة عند ظهور الخيار.
5. من Settings > Pages اختر Deploy from a branch، ثم main و /(root)، واضغط Save.
6. انتظر اكتمال النشر ثم افتح رابط GitHub Pages.

تنبيه: المساعد الحالي إرشادي محلي بإجابات معدة مسبقًا، وليس ذكاء اصطناعيًا متصلًا بنموذج خارجي. لا تضع مفاتيح API في ملفات الواجهة العامة.

ملاحظة مهنية: قائمة القضايا والعقود أمثلة تعريفية ولا تعني قبول كل ملف أو ضمان نتيجة. يجب مراجعة الاختصاص والوقائع والمستندات قبل تقديم رأي قانوني محدد.
